# Сайт Tripjot (список ожидания)

## Как устроена папка
- `public/` — сам сайт. Только эта папка попадает в интернет.
- `netlify.toml` — настройки Netlify (публиковать папку `public`, сборка не нужна).
- `README.md` — эти заметки (в интернет не попадают).

## Как обновлять сайт
Изменили файлы → в GitHub Desktop «Commit to main» → «Push origin». Netlify сам выложит новую версию через минуту.

Простой сайт из файлов, без сборки. Работает, если открыть `index.html` или загрузить папку на хостинг.

## Файлы
- `index.html` — главная страница (заголовок, калькулятор, как работает, почему Tripjot, скидка, вопросы, форма, низ страницы).
- `privacy.html` — политика конфиденциальности для списка ожидания (UK GDPR). Жёлтым выделены места, которые нужно заполнить: дата, имя владельца, почта, хостинг, сервис форм.
- `config.js` — **единственное, что нужно менять**: адрес формы (`formEndpoint`), почта для связи (`contactEmail`), имя владельца (`ownerName`).
- `app.js` — калькулятор, отправка формы, счётчики событий.
- `styles.css` — внешний вид по дизайну приложения (вариант D): в обеих темах зелёный акцент (в тёмной — светлее, мятный), эффект «жидкого стекла».
- `theme.js` — темы: Auto (как в телефоне/компьютере, меняется сама), Light, Dark. Кнопка вверху и переключатель внизу страницы. Выбор запоминается в браузере.
- `favicon.svg` — значок (сам меняет цвет в тёмной теме).
- Цвет сайта: два варианта — Copper (медное стекло, по умолчанию) и Sage (шалфейный). Переключатель — кружок в шапке рядом с кнопкой темы и «Sage / Copper» внизу. Для медного цвета значок вкладки — `favicon-copper.svg`.

## Калькулятор
мили в год = мили в неделю × 46; положено = 55p × первые 10 000 + 25p × остальные (35p с 6 апреля 2027 — переключится само);
разница = положено − (ставка работодателя × мили), не меньше 0; возврат = разница × 20% или 40%.
Проверка: 130 миль, 30p, 20% → £300 (точно £299).

## Форма
Заявки собирает **Netlify Forms** (`formEndpoint: "auto"`). На настоящем сайте форма отправляет заявку в Netlify (раздел Forms → waitlist). На этом компьютере (localhost) — тестовый режим: показывает «You're on the list», но ничего не отправляет.
Отправляет: email, first_name, role (home_carer / self_employed / other), consent, consent_text, signed_up_at, page и метки рекламы utm_* (если есть в ссылке).
Есть скрытая ловушка для спам-ботов (поле `company`).

## Счётчики
`app.js` отправляет события `cta_click`, `calculator_used`, `signup` в Umami / GoatCounter / Meta Pixel, если один из них подключён на странице. Пока ничего не подключено — события видны только в консоли браузера.
Если подключить Meta Pixel или другой инструмент с cookies — нужно обновить раздел Cookies в `privacy.html` и, скорее всего, добавить баннер согласия.
