# Сайт Tripjot (список очікування)

Простий сайт із файлів, без збирання. Працює, якщо відкрити `public/index.html` або завантажити папку `public` на хостинг.

## Як влаштована папка
- `public/` — сам сайт. Тільки ця папка потрапляє в інтернет.
- `netlify.toml` — налаштування Netlify (публікувати папку `public`, збирання не потрібне).
- `README.md` — ці нотатки (в інтернет не потрапляють).

## Як оновлювати сайт
Змінили файли → у GitHub Desktop «Commit to main» → «Push origin». Netlify сам викладе нову версію приблизно за хвилину.

## Файли в `public/`
- `index.html` — головна сторінка: заголовок, калькулятор, як це працює, чому Tripjot, знижка, питання, форма, низ сторінки.
- `privacy.html` — політика конфіденційності (UK GDPR) з двох частин: застосунок Tripjot (поїздки лише на iPhone, Apple для адрес/маршрутів, відгук поштою) і сайт зі списком очікування. Коротка адреса для App Store: `https://tripjot.app/privacy` (правило в `netlify.toml`).
- `config.js` — **єдине, що потрібно змінювати**: адреса форми (`formEndpoint`), пошта для зв'язку (`contactEmail`), ім'я власника (`ownerName`).
- `app.js` — калькулятор, надсилання форми, лічильники подій.
- `styles.css` — зовнішній вигляд: «рідке скло», дві колірні схеми (Copper — мідна, за замовчуванням; Sage — шавлієва), світла й темна тема.
- `theme.js` — тема (Auto — як у телефоні чи комп'ютері й змінюється сама, Light, Dark) і колір (Copper / Sage). Перемикачі внизу сторінки зараз приховані (атрибут `hidden` у `.theme-row`): сайт завжди Auto + Copper. Щоб повернути — прибрати `hidden` і в `theme.js` знову читати збережений вибір.
- `favicon.svg`, `favicon-copper.svg` — значок вкладки для шавлієвої та мідної схеми.
- `favicon.ico`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — той самий мідний значок у PNG/ICO: для Google (значок у пошуку), iPhone і логотипа в розмітці.
- `og-image.png` — картинка 1200×630 для прев'ю посилання у Facebook (вихідний файл — `../design-previews/og-image.svg`).

## Калькулятор
милі за рік = милі за тиждень × 46; належить = 55p × перші 10 000 + 25p × решта (35p з 6 квітня 2027 — перемкнеться саме);
різниця = належить − (ставка роботодавця × милі), не менше 0; повернення = різниця × 20% або 40%.
Перевірка: 130 миль, 30p, 20% → £300 (точно £299).
Вкладка Self-employed: відрахування = ті самі 55p/25p × милі за рік; менше податку = відрахування × 20% або 40%. Перевірка: 130 миль, 20% → £3,289 відрахування, £658 менше податку.

## Форма
Заявки збирає **Netlify Forms** (`formEndpoint: "auto"`). На справжньому сайті форма надсилає заявку в Netlify (розділ Forms → waitlist). На цьому комп'ютері (localhost) — тестовий режим: показує «You're on the list», але нічого не надсилає.
Надсилає: email, first_name, work_type (employed / self_employed / both) і job (care / other) — обидва вибори обов'язкові, consent, consent_text, signed_up_at, page і рекламні мітки utm_* (якщо вони є в посиланні).
Є прихована пастка для спам-ботів (поле `company`).

## Лічильники
Підключено **Umami** (cloud.umami.is, регіон EU, сайт `Tripjot`). Скрипт стоїть у `<head>` обох сторінок і рахує відвідування лише на `tripjot.app` (на localhost — ні).
`app.js` надсилає події `cta_click`, `calculator_used`, `signup` (з `role`). Їх видно в Umami → Tripjot → Events.
Umami не використовує cookies, тому банер згоди не потрібен. Якщо додати Meta Pixel або інший інструмент із cookies — треба оновити розділ Cookies у `privacy.html` і додати банер згоди.
